# 🚗 Автосалон — Аренда автомобилей

Учебный проект по дисциплине **«Web-технологии»**, посвящённый изучению объектно-ориентированного программирования, коллекций, LINQ и асинхронного программирования на **C#**.

## 📌 О проекте

Программа моделирует работу небольшого сервиса аренды автомобилей.

В проекте реализованы:

* иерархия классов автомобилей;
* наследование и полиморфизм;
* инкапсуляция и валидация данных;
* работа с интерфейсами и обобщёнными типами;
* коллекции `List<T>` и `Dictionary<TKey, TValue>`;
* LINQ-запросы;
* статистика и группировка данных;
* асинхронное выполнение операций;
* параллельная обработка с `Task.WhenAll`;
* обработка исключений;
* отмена асинхронных операций через `CancellationToken`.

## 🧱 Архитектура

### Базовый класс `Car`

`Car` является абстрактным базовым классом для автомобилей.

Он содержит общие характеристики:

* идентификатор;
* марку;
* модель;
* год выпуска;
* мощность;
* стоимость аренды.

Также реализованы:

* инкапсуляция стоимости аренды;
* проверка корректности цены;
* изменение стоимости через метод `ChangePrice()`;
* абстрактный метод `PrintInfo()`.

### Наследники

В проекте представлены две специализированные категории автомобилей:

```text
              Car
             /   \
            /     \
     SportsCar   BusinessCar
```

**`SportsCar`** содержит дополнительную характеристику максимальной скорости.

**`BusinessCar`** содержит характеристику класса салона.

Каждый класс переопределяет метод `PrintInfo()`, демонстрируя механизм полиморфизма.

## 🔌 Сервис работы с автомобилями

Для работы с объектами используется обобщённый интерфейс:

```csharp
IItemService<T>
```

Он определяет операции:

* добавление объекта;
* получение всех объектов;
* поиск по ID;
* поиск по марке.

Реализация:

```csharp
CarService : IItemService<Car>
```

Сервис хранит автомобили во внутренней коллекции:

```csharp
List<Car>
```

---

## 📦 Коллекции

### `List<Car>`

Основная коллекция автомобилей содержит несколько объектов разных типов:

```csharp
List<Car> carsList =
[
    sportsCar,
    businessCar,
    sportsCar2,
    businessCar2,
    sportsCar3,
    businessCar3
];
```

Благодаря базовому типу `Car` одна коллекция может содержать объекты разных классов.

### `Dictionary<int, Car>`

Для быстрого поиска автомобиля по идентификатору используется:

```csharp
Dictionary<int, Car>
```

Поиск выполняется безопасно через:

```csharp
TryGetValue()
```

## 🔎 LINQ

В проекте используются основные методы LINQ:

### Фильтрация

```csharp
Where()
```

Позволяет получить автомобили, соответствующие условию.

### Сортировка

```csharp
OrderByDescending()
```

Используется для сортировки автомобилей по стоимости аренды.

### Выбор данных

```csharp
Select()
```

Позволяет сформировать выборку только с необходимыми полями.

### Агрегатные операции

Используются:

```text
Count()
Sum()
Average()
Min()
Max()
```

Они позволяют получить статистику по стоимости аренды.

### Группировка

```csharp
GroupBy()
```

Используется для распределения автомобилей по категориям.

## ⚡ Асинхронное программирование

Для демонстрации асинхронной работы создан сервис:

```csharp
CarAsyncService
```

В нём реализованы:

### `async / await`

Асинхронная загрузка списка автомобилей:

```csharp
public async Task<List<Car>> GetCarsAsync()
```

### `Task.Delay`

Используется для имитации асинхронной операции.

### `Task.WhenAll`

Несколько поисковых операций могут выполняться параллельно:

```csharp
await Task.WhenAll(
    searchTask1,
    searchTask2,
    searchTask3
);
```

### Обработка исключений

Используется конструкция:

```csharp
try
{
    // операция
}
catch
{
    // обработка ошибки
}
finally
{
    // завершающие действия
}
```

### `CancellationToken`

Асинхронная операция поддерживает отмену:

```csharp
CancellationToken
```

В программе также демонстрируется автоматическая отмена операции через:

```csharp
CancelAfter()
```
